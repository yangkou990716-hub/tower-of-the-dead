# iPhone 實機測試（renderer-3d）

網址：https://yangkou990716-hub.github.io/tower-of-the-dead/
用 **Safari** 開（不要在 Claude App 內開，效能與快取行為不同）。每項記下結果；有問題附截圖。

## A. 首次載入與快取（需先清除網站資料：設定 → Safari → 進階 → 網站資料 → 刪除此網站）
1. 開 `…/?r=3d&debug=1`，等標題畫面右下出現「已可離線遊玩」。記下從點網址到標題出現的秒數。
2. 踏入塔中 → 出發。記下從按「出發」到看到房間的秒數（中間會出現「載入 3D 資源 n/m」）。
3. 左側 debug 框記下：後端（WebGPU／WebGL 2）、畫質、fps、DC、△、KayKit MB／秒。

## B. 遊玩 10 分鐘（平衡畫質，橫拿）
4. 正常玩，至少換 10 間房。每隔約 2 分鐘記一次 debug 框的 fps。
5. 記下 debug 框的「換房 n 次 / 最長 ms」。
6. 有沒有自動降級提示（「已自動降為效能畫質」）？出現在第幾分鐘？
7. 手機是否明顯發燙、有沒有閃退。

## C. 暫停與恢復
8. 遊玩中按 Home 回主畫面 30 秒再回來：是否停在暫停面板、時間沒跑、能繼續玩。
9. 遊玩中拉下通知中心 / 鎖屏 1 分鐘再回來：同上，畫面是否正常（沒有全黑或花屏）。

## D. 安裝與離線
10. 分享 → 加入主畫面。從主畫面開啟（這是另一份資料，畫面預設 2D）：設定 →「畫面（實驗）」選 3D → 完成（會重新載入）。
11. 進一次遠征，讓模型下載完。
12. 開飛航模式，完全關掉 App 再從主畫面開：能否啟動、讀檔、進房間、角色是騎士與骷髏（不是簡單幾何形狀）、存檔後重開還在。

## E. 2D 退路
13. 設定 → 畫面選 2D：能正常玩、存檔共用。
14. 若 3D 曾出現「3D 畫面中斷，已切回 2D」提示，記下當時在做什麼。
